Isolated .NET SDK

Install. Use. Verify. Remove.

Project overview

Install and manage exact .NET SDK versions without modifying system-wide installations or PATH. Supports PowerShell on Windows and Bash on Linux/macOS.

.NETDeveloper toolsPowerShellBashCross-platform

Isolated .NET SDK lets you install, audit, verify, and remove selected SDK versions in your own directory. Evaluate new SDK releases or reproduce version-specific behavior without altering the machine's normal development setup.

Key features

  • Install exact .NET SDK versions in a user-owned directory
  • Keep system-wide SDK installations and PATH unchanged
  • Audit and verify installed SDK versions
  • Remove isolated versions when no longer needed
  • Use PowerShell on Windows or Bash on Linux and macOS

Why it matters

Different projects require different SDK versions. Testing prerelease software should not destabilize a working machine. The isolated approach makes selection explicit and provides separate operations for inspection, verification, and removal.

Design boundaries

Isolation here refers to SDK files and installation paths, not a security sandbox. The SDK still runs with your normal permissions. Use the published documentation for exact commands, platform requirements, and current limitations.
